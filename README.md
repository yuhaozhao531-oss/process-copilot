# process-copilot（序安 Process Sentinel）

2026-09-01 起从零重写。此前基于 Tennessee Eastman Process 数据"验证方法论"的实现逻辑存在问题，已整体删除。

## 定位

只读采集数据，不接管 DCS 生产控制；输出仅作预测/预警/仿真建议，供工艺工程师/操作员参考，不替代人工决策，也不以减少用人为目标——价值在于让人更快看到问题、更快拿到可选方案。

## 场景与数据来源（按开发顺序）

| 场景 | 数据 | 状态 |
|---|---|---|
| ⑥ 以渣定产物料平衡（`capacity_planner.py`） | 报告 2.1 节化学计量比，纯规则计算 | 已实现 |
| ⑤ 交椅山渣库早期预警 | 合成示意数据，依据报告 2017/2025 年真实事件时间线 | 待实现 |
| ① 湿法磷酸/漏洞一方法论验证 | Kaggle 铁矿浮选真实数据（浮选投料环节，非磷化工数据） | 待实现，许可证待确认 |
| ③ 磷酸铁沉淀方法论验证 | Agtrup 化学除磷真实 SCADA 数据（CC BY-NC 3.0，非商业用途） | 待实现 |
| ② 净化磷酸萃取 / ④ 回转窑烟气制酸 | 无可用真实数据 | 维持留白，等真实息烽数据 |

每个场景的代码和界面必须显式披露数据来源与验证边界，不得让人误以为是息烽园区真实数据。
